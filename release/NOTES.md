## Multi-CLI 1.0.0

The first stable release of Multi-CLI.

### Highlights

- Run isolated account profiles for 17 coding CLIs, IDEs, and desktop agents.
- Keep supported profiles open at the same time without repeated account switching.
- Use file overlays, process credentials, whole-root isolation, or owned OS users according to each adapter's verified boundary.
- Create, launch, inspect, rename, clone, migrate, export, import, and remove profiles from one CLI.
- Continue supported sessions between profiles without copying declared credentials.
- Install on Windows, macOS, and Linux with platform-native scripts.

### Downloads

- `multi-cli-v1.0.0-windows.zip` for Windows PowerShell.
- `multi-cli-v1.0.0-linux-macos.tar.gz` for Bash on Linux or macOS.
- `SHA256SUMS` to verify both archives.

Check the [support matrix](https://github.com/Spielewoy/multi-cli/blob/main/docs/support-matrix.md) before relying on a specific tool, platform, or authentication mode.
