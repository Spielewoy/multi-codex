## Multi-CLI 1.0.0

The first stable release of Multi-CLI.

### Highlights

- Use multiple accounts at the same time across 17 AI coding tools.
- Keep each account's credentials separate.
- Create, launch, inspect, rename, clone, migrate, export, import, and remove profiles from one CLI.
- Move supported sessions between profiles without copying credentials.
- Install on Windows, macOS, and Linux with platform-native scripts.

### Downloads

- `multi-cli-v1.0.0-windows.zip` for Windows PowerShell.
- `multi-cli-v1.0.0-linux-macos.tar.gz` for Bash on Linux or macOS.
- `SHA256SUMS` to verify both archives.

Check the [AI tool support table](https://github.com/Spielewoy/multi-cli#supported-ai-tools) before relying on a specific tool, platform, or sign-in method.
