# Support

- Bugs: open a [bug report](https://github.com/Spielewoy/multi-cli/issues/new?template=bug.yml).
- Usage: open a [usage question](https://github.com/Spielewoy/multi-cli/issues/new?template=question.yml).
- New AI tools: open an [AI tool request](https://github.com/Spielewoy/multi-cli/issues/new?template=ai-tool.yml).
- Vulnerabilities: use [private security reporting](https://github.com/Spielewoy/multi-cli/security/advisories/new).

Run `multi-cli doctor` first. Include the Multi-CLI version, operating system, shell, AI tool, reproduction steps, and sanitized output. Never post credentials or private account data.
